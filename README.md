# Burkit Team

Репозиторий команды Burkit для хакатон-проекта. В текущей ветке `TeamLead` находятся вспомогательные Python-модули для оценки задач и загрузки демонстрационных данных.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `rating.py` | Расчёт полноты и рейтинга задачи по заполненным полям. |
| `seed_data.py` | Набор демонстрационных данных для черновиков, задач, команд и заявок. |

## Оценка задачи — `rating.py`

Функция `calculate_task_rating(task_data)` принимает словарь с данными задачи и возвращает словарь с итоговым баллом, статусом и списком незаполненных полей. Поле засчитывается, если его значение — непустая строка.

| Поле | Вес |
| --- | ---: |
| `context_need` — контекст и потребность | 20 |
| `data_materials` — данные и материалы | 20 |
| `expected_result` — ожидаемый результат | 15 |
| `success_criteria` — критерии успеха | 15 |
| `constraints` — ограничения | 10 |
| `target_users` — целевые пользователи | 10 |
| `business_contact` — связь с бизнесом | 10 |

Статус определяется по сумме баллов:

| Баллы | Статус |
| ---: | --- |
| 90–100 | `Приоритетная` |
| 70–89 | `Готовая` |
| 40–69 | `Рабочая` |
| 0–39 | `Черновик` |

В `missing_fields` для каждого незаполненного поля возвращаются его ключ, доступный бонус и русскоязычная подсказка для интерфейса.

```python
from rating import calculate_task_rating

task = {
    "context_need": "Заявки теряются между каналами.",
    "data_materials": "Обезличенный реестр заявок.",
    "expected_result": "Единый дашборд заявок.",
    "success_criteria": "Обработка заявки занимает до 10 минут.",
    "constraints": "Срок — две недели.",
    "target_users": "Менеджеры учебного центра.",
    "business_contact": "Telegram: @edu_center_admin",
}

rating = calculate_task_rating(task)
print(rating["score"], rating["status"])
```

Функцию можно импортировать в обработчик FastAPI и передавать ей словарь с данными задачи.

## Демонстрационные данные — `seed_data.py`

Модуль предоставляет константу `SEED_DATA` — обычный Python-словарь с примерами для интерфейса или первоначального наполнения приложения. В нём есть четыре набора:

- `drafts` — 5 черновиков идей с названием, исходным описанием и отраслью;
- `tasks` — 5 задач с описаниями, критериями, баллами и статусами;
- `teams` — 5 команд с интересами, навыками и специализацией;
- `applications` — 2 заявки команд на задачу, включая идею, план, сроки и ссылку на прототип.

```python
from seed_data import SEED_DATA

drafts = SEED_DATA["drafts"]
tasks = SEED_DATA["tasks"]
```

Данные являются примерами, объявлены в коде и сами по себе не записываются в базу данных.

## Использование

Модули используют только стандартные возможности Python и не требуют сторонних библиотек. Сохраните файлы в корне проекта, чтобы импортировать их по имени модуля, как показано в примерах.
